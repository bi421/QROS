# QROS Execution Roadmap — Batch Protocol

## Milestone 1 — Architecture Freeze
Freeze the seven-layer boundary and Golden Path.

## Milestone 2 — Golden Path API Batch
Complete Dataset -> Research Run -> Evidence -> Claim -> Result with tenant isolation, role matrix, persistence and provenance.

## Milestone 3 — Golden Path Integration
Run one authenticated workflow in staging and measure Time -> First Valid Research Result.

## Milestone 4 — Production Validation
Validate deployment, migrations, backups, recovery, observability, rate limits and tenant attack tests.

## Milestone 5 — Real User Validation
Use the workflow with real users and fix workflow friction before major new research features.

## Milestone 6 — Monetization
Add billing/entitlements justified by observed usage.

## Batch Protocol
Inspect -> Design -> Implement -> Test -> Fix -> Security Audit -> Regression -> Diff Audit -> CI -> Report.

STOP only for irreversible production data changes, payment-provider selection, ambiguous security boundaries, cross-domain architecture choices, or missing external credentials.
