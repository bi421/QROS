# QROS Product Flow — Golden Path V1

The first product outcome is a complete user workflow, not a collection of APIs.

REGISTER -> CREATE WORKSPACE -> UPLOAD DATASET -> CREATE RESEARCH RUN -> RUN ANALYSIS -> GENERATE EVIDENCE -> CREATE/ATTACH CLAIM -> VIEW RESULT

## Product objects
1. Dataset / immutable version
2. Research Run / status and provenance
3. Result / manifest and artifact provenance
4. Evidence / claim-level support
5. Research Claim / governed research intent

## Primary metric
Time -> First Valid Research Result: elapsed time from registration to the first result satisfying QROS integrity and provenance gates.
