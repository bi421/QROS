# Historical Research Report Archive

Use this directory for retained historical audits and reports that are no longer active architecture or product documentation.

## Naming

Store material under `YYYY-MM/` using descriptive filenames. Example:

`archive/reports/2026-09/forensic-audit-2026-09-15.md`

## Rule

Historical evidence is preserved, but it is not an active source of truth. Current architecture and operating rules belong in `AI_CONTEXT.md` and the canonical `docs/` documents.

Do not place new one-off dumps at repository root.
